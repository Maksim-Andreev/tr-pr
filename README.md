# Три причины

Приложение для Ани: три причины наугад, каждая твоим голосом.

## Что внутри

    index.html            приложение
    reasons.json          158 причин — единственный файл, который ты редактируешь
    audio/                164 записи: 001.wav … 158.wav + love-1.wav … love-6.wav
    studio.html           запись новых причин (нужен http, не файл с диска)
    sw.js                 работа без интернета
    manifest.webmanifest  иконка и полноэкранный режим
    icons/

## Выложить

1. github.com → **New repository** → Public → Create
2. `https://github.com/ИМЯ/РЕПО/upload/main` → перетащи все файлы.
   Папку `audio` двумя заходами: в веб-загрузчике максимум 100 файлов за раз.
3. **Settings → Pages** → Branch `main`, папка `/ (root)` → Save
4. Через две минуты: `https://ИМЯ.github.io/РЕПО/`

## Поставить ей на телефон

На её айфоне, **обязательно в Safari** (в Chrome такого пункта нет):
открыть ссылку → **Поделиться** → **На экран «Домой»** → Добавить.

Дальше это обычное приложение: своя иконка, весь экран, работает без связи.

## Добавить причину потом

На github.com открой `reasons.json` → карандаш → добавь строку в конец списка:

    { "id": "159", "t": "Потому что ..." }

Запиши `audio/159.wav` через studio.html и загрузи. Живёт через минуту,
ей ничего переустанавливать не надо.

**id никогда не меняется** — по нему находится запись. Порядок в списке
можно менять как угодно, id остаётся за своей строкой.

## Если поменяешь index.html

Открой `sw.js` и подними версию: `three-reasons-v8` → `-v9`.
Для `reasons.json` и новых записей этого делать не нужно.

## Мелочи

- Сохранённые сердечком причины живут в браузере её телефона. Переживают
  обновления, но исчезнут, если удалить иконку с экрана.
- «Я тебя люблю» сверху: шесть записей, при каждом нажатии играет другая.
  Текст на кнопке — `love.text` в reasons.json.
- Чтобы закрепить причину за датой, добавь в `special`:
  `{ "on": "09-17", "id": "063", "t": "Потому что ты существуешь" }`
  `"ММ-ДД"` — каждый год, `"ГГГГ-ММ-ДД"` — один раз.
